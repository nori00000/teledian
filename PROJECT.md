# Project Metadata / 프로젝트 메타데이터

## Overview / 개요

Teledian is an Obsidian desktop plugin that embeds Telegram Web in an Obsidian sidebar. This repository is a public fork of `reallygood83/teledian`.

Teledian은 Telegram Web을 Obsidian 사이드바에 임베드하는 Obsidian 데스크톱 플러그인입니다. 이 레포는 `reallygood83/teledian`의 공개 fork입니다.

## Purpose / 목적

- Open Telegram Web inside an Obsidian desktop sidebar.
- Support a configurable default chat, panel side, and web version.
- Make the fork's upstream attribution, service relationship, and copyright boundaries clear.

- Obsidian 데스크톱 사이드바 안에서 Telegram Web을 엽니다.
- 기본 채팅, 패널 위치, 웹 버전 설정을 지원합니다.
- fork의 upstream 표시, 서비스 관계, 저작권 범위를 명확히 합니다.
